## 認証フローのHTTPクライアント経由ルーティング

ログインの生の認証フローが共有HTTPクライアント抽象化を使用するようにマイグレーションされた。

[参考リンク](https://github.com/openai/codex/pull/31637)

## Codex Appsのオプションファイルフィールドのツールスキーマフィルタリング

Codex Appsがモデルにファイルパラメータを公開する方法が調整され、ツールスキーマに基づいてオプションフィールドがフィルタリングされるようになった。

[参考リンク](https://github.com/openai/codex/pull/31686)

## 外部プロセス解決失敗時のインプロセスv8フォールバック

コンパニオンバイナリが見つからない場合にインプロセスのv8にフォールバックするcode-modeのロジックが追加された。

[参考リンク](https://github.com/openai/codex/pull/31899)

## リモートMCP stdio行のサイズ制限

JSON-RPCおよび診断出力行にサイズ制限が実装され、悪意のあるエグゼキュータによる無制限メモリ増大が防止されるようになった。

[参考リンク](https://github.com/openai/codex/pull/31805)

## MCP OAuthクレデンシャルストアの解決とピンニング

[参考リンク](https://github.com/openai/codex/pull/30293)
