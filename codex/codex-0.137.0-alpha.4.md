## Windows TUIレンダリングの修正

Windows TUIのレンダリング崩れが修正され、描画前に仮想ターミナルモードが復元されるようになった。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.137.0-alpha.4)

## ワークスペース固有の使用制限メッセージ

クレジットや支出上限の超過時に、ワークスペース固有の使用制限メッセージが表示されるようになった。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.137.0-alpha.4)

## プラグインスキルのアイコン共有

プラグインスキルが共有プラグインレベルのアイコンアセットを再利用できるようになった。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.137.0-alpha.4)

## 権限プロファイルメタデータの保持

オートレビューランタイム設定の同期時に、アクティブな権限プロファイルのメタデータが保持されるようになった。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.137.0-alpha.4)
