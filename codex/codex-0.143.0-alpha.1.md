## Windows システムプロキシリゾルバーの追加

PAC 設定、WPAD 自動検出、静的プロキシ、バイパスルールを含む Windows システムプロキシ解決が実装された。

[参考リンク](https://github.com/openai/codex/pull/26708)

## CDP 要件機能の登録

CDP 要件フィーチャーフラグが登録された。

[参考リンク](https://github.com/openai/codex/pull/28769)

## リモートプラグインのフィーチャー ID 取得

カタログに `openai-curated-remote` が含まれる場合にフィーチャープラグイン ID を取得し、バックエンドキュレーションによるリモートフィーチャープラグインセットが有効になった。

[参考リンク](https://github.com/openai/codex/pull/29485)

## バンドル OpenSSL の 3.6.3 へのアップグレード

ベンダー化された Linux musl ビルドのバンドル OpenSSL が 3.5.5 から 3.6.3 にアップグレードされ、セキュリティパッチが適用された。

[参考リンク](https://github.com/openai/codex/pull/29487)
