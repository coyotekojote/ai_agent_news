## 中断されたプロンプトの会話履歴保持

出力のない中断されたプロンプトがトランスクリプトに保持されるようになった。次の指示には空のコンポーザーが開かれ、セーフティバッファリングプロンプトは別途追跡される。

[参考リンク](https://github.com/openai/codex/pull/33198)

## 実行権限パスとコアモデルの分離

コアファイルシステム権限タイプが `AbsolutePathBuf` に変換され、`PathUri` に変換するexec固有の型が追加された。レガシーの読み取り/書き込みルートタプルが名前付き構造体に置き換えられた。

[参考リンク](https://github.com/openai/codex/pull/33200)

## TUIプロンプト編集時の会話分岐

以前のTUIプロンプトを編集する際に、インプレースでロールバックするのではなく、選択されたプロンプトの直前で会話をフォークするようになった。元の会話は保持され、画像、テキスト、メンションバインディングとともにプロンプトが再開される。

[参考リンク](https://github.com/openai/codex/pull/33201)

## スレッド入力復元時の実行中状態の保持

スレッド入力スナップショットに明示的な復元モードが追加され、実行中ターン状態とともにペンディングステア割り込みフラグが保持されるようになった。

[参考リンク](https://github.com/openai/codex/pull/33203)

## セーフティバッファされたターンのフォークスレッドでのリトライ

バッファされたターンを中断し、先行する完了済みターンの後でフォークし、より高速なモデルと低い推論努力で送信するようになった。ソーススレッドはそのまま維持される。

[参考リンク](https://github.com/openai/codex/pull/33207)

## セッション状態とセッションI/Oの分離

統合された `Codex` ラッパーが、独立した `Arc<Session>` と `SessionIo` ハンドルに分離された。スレッド管理とガーディアンレビューが更新された。

[参考リンク](https://github.com/openai/codex/pull/33209)

## リトライ・編集時のスレッドコンテキスト保持

実験的な `beforeTurnId` が `thread/fork` に追加され、TUIバックトラッキングとセーフティリトライでbefore-turnフォークが使用されるようになった。

[参考リンク](https://github.com/openai/codex/pull/33211)

## Python SDK 0.144.4安定版リリースの準備

`openai-codex` Python SDKが安定版としてマークされ、バージョン付きランタイム依存関係がCodex CLI `0.144.4` に合わせられた。プロトコルモデルが再生成された。

[参考リンク](https://github.com/openai/codex/pull/33213)

## 環境・プラグイン解決パスの計測追加

環境スナップショット、ケイパビリティ/エグゼキュータプラグイン解決、`AGENTS.md` リフレッシュ、MCPランタイム操作に名前付きトレーシングスパンが追加された。

[参考リンク](https://github.com/openai/codex/pull/33223)

## スキルメンションとシェルパラメータの曖昧さ解消

`$` プレフィックス付きクエリがスキル候補、シェル変数、確定的シェルパラメータ、または曖昧な名前に分類されるようになった。ロードされたメンションに一致する曖昧な名前に対してのみ補完が提供される。

[参考リンク](https://github.com/openai/codex/pull/33232)

## サフィックス付きバウンドメンション周辺のスキル補完修正

サフィックス付きバウンドメンションに `$` メンション境界ルールが使用されるようになった。隣接トークンがバウンドの場合は編集可能なスキルトークンにフォールバックする。

[参考リンク](https://github.com/openai/codex/pull/33237)

## TUIコンポーザータブの単一列スペースレンダリング

タブがラッピング/レンダリング用に単一列スペースに置き換えられるようになった。元の編集可能テキストとバイト範囲は保持される。

[参考リンク](https://github.com/openai/codex/pull/33239)

## 自動コンパクションフォールバックトークンバジェット設定の追加

トークンバジェット設定に `auto_compact_fallback_prompt` と `auto_compact_fallback_buffer_tokens` が追加された。プロンプトは2,000バイトに制限される。

[参考リンク](https://github.com/openai/codex/pull/33243)

## 選択された環境接続遷移の報告

接続/切断状態が追跡され、実験的な `thread/environment/connected` および `/disconnected` 通知が発行されるようになった。

[参考リンク](https://github.com/openai/codex/pull/33251)

## 自動コンテキストロールオーバー前のフォールバックフェーズ追加

コンテキストコンパクション前にフォールバックプロンプト用のトークンが予約されるようになった。ベース制限でフォールバックが開発者メッセージとして注入され、予約が使い果たされるとロールオーバーされる。

[参考リンク](https://github.com/openai/codex/pull/33255)
