## Windows サンドボックスの Git safe.directory 修正

サンドボックス環境内のリンクされたワークツリーに対する Git safe.directory インジェクションが修正された。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.129.0-alpha.13)

## Git コミット帰属設定のドキュメント追加

`config.toml` の `codex_git_commit` フィーチャーによるコミット帰属設定のドキュメントが追加された。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.129.0-alpha.13)

## スキルウォッチャーの app-server 移行

スキル更新通知が codex-core から app-server に移動され、アーキテクチャの分離が改善された。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.129.0-alpha.13)

## ツールスペックの core ハンドラ移行

ビルトインツールスペックのコンストラクタが codex-tools から codex-core に機械的に移動された。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.129.0-alpha.13)

## マーケットプレイスソースフィルタリングとプラグイン共有コンテキスト

marketplaceKinds フィルタリングが実装され、プラグインサマリーに shareContext が公開された。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.129.0-alpha.13)
