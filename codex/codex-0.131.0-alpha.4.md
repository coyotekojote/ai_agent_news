## ネットワークコンテキストレンダリングのコンパクト化

ネットワークコンテキストのレンダリングがコンパクト化され、表示効率が向上した。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.131.0-alpha.4)

## Python ランタイムホイールの PyPI 配布

Python ランタイムパッケージがプラットフォーム固有のリソースバイナリをサポートするようになった。Linux 用の bwrap や Windows 用のランタイムヘルパーを含むホイールが PyPI で配布されるようになった。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.131.0-alpha.4)
