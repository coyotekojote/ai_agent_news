## TUIの強化

TUIがより豊富なセッション制御と表示機能を提供するようになった。データ駆動のサービスティアコマンド、ブレンドされたトークン使用量表示、権限・承認モード、有効なワークスペースルート、レスポンシブなMarkdownテーブルが追加された。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.131.0)

## 統合メンションシステム

`@`メンションピッカーがファイル、ディレクトリ、プラグイン、スキルをapp-serverのプラグインメタデータに基づく単一のインターフェースに統合された。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.131.0)

## プラグインワークフローの改善

プラグイン管理にマーケットプレイスCLIコマンド、バージョン対応の共有機能、共有チェックアウト機能、改善された共有ワークスペースバケット構成、デフォルト有効のプラグインフックが追加された。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.131.0)

## リモートワークフローのサポート

リモートワークフローにデーモン管理のリモートコントロール、ランタイム有効化/無効化API、ステータス読み取り、レジストリベースの構成済みリモート環境が追加された。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.131.0)

## Python SDKの移行

Python SDKが`openai-codex` / `openai_codex`に移行され、ピン留めされたランタイム生成型、並行ターンルーティング、承認モード、統合テストカバレッジが追加された。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.131.0)

## 診断ツールの追加

`codex doctor`コマンドが追加され、ランタイム、認証、ターミナル、ネットワーク、設定、ローカル状態にわたるサポート対応の診断が可能になった。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.131.0)

## バグ修正

TUIのURL折り返し、ライトモードでの選択コントラスト、tmuxでのShift+Enterの動作、`/review`のMCP起動ステータス、`/side`のEscハンドリング、ネットワーク承認履歴のレンダリングが修正された。Windowsサンドボックスでの拒否読み取りルール、スコープ付き書き込みルート、ファイアウォールポリシーの有効性、PowerShellエッジケースの処理が改善された。権限昇格時の管理読み取り制限の保持とワークスペースルートの権限プロファイル解決が改善された。SQLiteデータの保持、フェイルクローズド状態の処理、リカバリパス、メタデータ同期の失敗軽減によるapp-serverとローカル状態の起動安全性が向上した。ルートワークツリーフックの一貫した使用、ヘルパーコマンドでのリポジトリフック/fsmonitor設定の無視、ローカルMCP OAuthコールバックのバインド、置き換えられたログイントークンの失効が実装された。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.131.0)

## コード品質の改善

大規模なTUI ChatWidget、ヒストリー、コンポーザーモジュールがフォーカスされたコンポーネントに分割された。エクステンションとツールの内部構造が抽出され、共有ツールコントラクトやガーディアン/メモリエクステンション基盤が整理された。廃止されたツールパス、フィーチャーフラグ、設定ゲート、レガシーフックが削除された。

[参考リンク](https://github.com/openai/codex/releases/tag/rust-v0.131.0)
