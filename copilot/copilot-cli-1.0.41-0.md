## 非インタラクティブモードでのファイル添付サポート

`-p/--prompt` を使用した非インタラクティブモードで `--attachment` フラグが追加され、画像やドキュメントファイルを初期プロンプトに添付できるようになった。

[参考リンク](https://github.com/github/copilot-cli/releases/tag/v1.0.41-0)

## ファイル編集の信頼性向上

ファジーまたは位置ずれしたエディットブロックからの回復メカニズムが改善され、ファイル編集の信頼性が向上した。

[参考リンク](https://github.com/github/copilot-cli/releases/tag/v1.0.41-0)

## バグ修正

- `./` パスでの @メンション補完が正しく動作するようになり、ディレクトリの末尾の不要なスペースが除去された
- 補完候補でプロジェクトファイルがワークスペースルートより前に表示されるようになった
- Windows で Node 24.x の V8 クラッシュが回避され安定性が向上した
- セッションファイル内の Unicode 行区切り文字が正しく読み込まれるようになった
- 推論エフォートピッカーのヒントテキストの表示間隔が修正され、「Esc to cancel」メッセージが正しく表示されるようになった

[参考リンク](https://github.com/github/copilot-cli/releases/tag/v1.0.41-0)
