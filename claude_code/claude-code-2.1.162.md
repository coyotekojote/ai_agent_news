## claude agentsの改善

`claude agents --json`に`waitingFor`フィールドが追加され、待機中のセッションが何でブロックされているか（例：権限プロンプト）が表示されるようになった。

`claude agents`のライブステータステキスト（ツール引数、返信、プロンプト、実行出力）が、広いターミナルで60〜120カラムで切り詰められていた問題が修正され、ターミナル全幅を使用するようになった。

`claude agents`の長いセッション名が40カラムで切り詰められていた問題が修正され、ターミナル幅に応じて名前カラムが拡大するようになった。

`claude agents`でバックグラウンドサービス再起動後にアタッチを試みると最初の試行でセッションリストに戻ってしまう問題が修正された。

`claude agents`でCtrl+Vによる画像ペーストがディスパッチ入力とセッション返信ボックスで動作しない問題が修正され、画像がない場合はヒントが表示されるようになった。

`←`キーでのセッションバックグラウンド化時にバックグラウンドサービスが起動できない場合、会話が失われていた問題が修正され、失敗した行としてリストに残りEnterで復帰可能になった。

agentsビューからの返信送信に失敗した場合に返信が失われていた問題が修正され、次のセッション開始時に配信されるようキューに入れられるようになった。

[参考リンク](https://code.claude.com/docs/en/changelog)

## ツール関連の改善

`--tools`でGrep/Globを明示的に指定した場合、組み込み検索を持つネイティブビルドで専用検索ツールが提供されるようになった（以前はこれらの名前はサイレントに無視されていた）。

LSPツールの`workspaceSymbol`操作が結果を返さなかった問題が修正され、`query`パラメータを受け取りLanguage Serverに渡すようになった。

[参考リンク](https://code.claude.com/docs/en/changelog)

## UI/UXの改善

`/effort`で選択したレベルが新しいセッションのデフォルトとして保持されることが確認表示されるようになった。

オートコンプリートメニューでスラッシュコマンドをクリックすると、即座に実行されるのではなくプロンプトに入力されるようになった。Enterで実行する。

Remote Controlがスタートアップメッセージの代わりにセッションリンク付きの常設フッターピルとして表示されるようになった。

WindsurfがDevin Desktopにリネームされ、`/ide`メニュー、`/terminal-setup`、`/scroll-speed`に反映された。

起動メッセージが整理され、通知が重要度別にグループ化され、セッション情報とアナウンスが1行にまとめられるようになった。

起動時の警告がより短く明確に書き直され、各警告に具体的な修正方法が付記されるようになった。

ディープリンク/事前入力プロンプトの警告が、スクロールで消えるのではなく、操作するまで入力欄の下にピン留めされるようになった。

失敗したターンが複数行の赤いエラーブロックではなくコンパクトな警告行で表示されるようになった。

「Claude in Chrome enabled」「marketplace installed」のスタートアップメッセージが削除され、モデル自動更新とチームオンボーディングヒントがロゴ下の静かな通知として表示されるようになった。

[参考リンク](https://code.claude.com/docs/en/changelog)

## セキュリティ・権限の修正

WebFetch権限ルールが組み込みプリアプルーブドドメインに適用されない問題が修正され、明示的な`WebFetch(domain:...)`のdeny/ask/allowルールがプリアプルーブドホストの自動許可よりも優先されるようになった。

Windows権限ルールがバックスラッシュ（`~\`、`\\server\share`）やパスの大文字小文字バリアントで一致しない問題、およびRead denyルールがGlob/Grep結果からファイルを非表示にしない問題が修正された。

[参考リンク](https://code.claude.com/docs/en/changelog)

## 安定性の修正

設定ディレクトリが読み取り専用または書き込み不可の場合にサイレントに起動がハングする問題が修正され、インメモリ設定で起動しスタートアップエラーを表示するようになった。

ターンの最初にEsc（中断）を送信するとstream-json/SDKセッションでサイレントにドロップされ、「Interrupted」フィードバックなしにターンが実行され続ける問題が修正された。

API 400 `no low surrogate in string`エラーが分類器サイドクエリやMCPサーバー説明文の切り詰め境界付近の絵文字で発生する問題が修正された。

MCPのサーバーごとの`timeout`設定値が1000ms未満の場合、すべてのツール呼び出しを中止する1秒のウォッチドッグに切り上げられていた問題が修正された。1000ms未満の値は無視され（`MCP_TOOL_TIMEOUT`またはデフォルトにフォールバック）、`claude mcp get`で注記されるようになった。

クロスセッションメッセージング（`SendMessage`）が`CLAUDE_CODE_TMPDIR`や`$TMPDIR`が深いディレクトリを指す場合にサイレントに壊れる問題が修正された。

`claude agents`から実行中のバックグラウンドセッションを開く際にアタッチ前に5秒間停止する問題が修正された。

バックグラウンドサービスの起動と`claude update`の検証が、5秒後に失敗するのではなく、エンドポイントセキュリティスキャンの完了を待機するようになった。

バックグラウンドディスパッチのスポーン失敗時にerrnoが利用できない場合、エラークラス名が報告されるようになった。

[参考リンク](https://code.claude.com/docs/en/changelog)
