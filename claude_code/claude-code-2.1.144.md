## バックグラウンドセッションの/resumeサポート

`/resume`がバックグラウンドセッションに対応し、`claude --bg`やエージェントビューから開始されたセッションがインタラクティブセッションと一緒に`bg`マーク付きで表示されるようになった。

[参考リンク](https://code.claude.com/docs/en/changelog)

## バックグラウンドサブエージェント完了通知に経過時間表示

バックグラウンドサブエージェントの完了通知に経過時間が表示されるようになった（例：「Agent completed · 3h 2m 5s」）。

[参考リンク](https://code.claude.com/docs/en/changelog)

## /pluginブラウズ・ディスカバーペインに最終更新日表示

`/plugin`のブラウズおよびディスカバーペインにプラグインの最終更新日が表示されるようになった。

[参考リンク](https://code.claude.com/docs/en/changelog)

## /modelコマンドの動作変更

`/model`が現在のセッションのみモデルを変更するようになった。モデルピッカーで`d`を押すと新しいセッションのデフォルトを設定できる。

[参考リンク](https://code.claude.com/docs/en/changelog)

## 「extra usage」から「usage credits」への名称変更

CLI全体で「extra usage」が「usage credits」に名称変更された。`/extra-usage`は`/usage-credits`に変更（旧名称も引き続き使用可能）。

[参考リンク](https://code.claude.com/docs/en/changelog)
