## スラッシュスキルの複数同時呼び出し対応

`/skill-a /skill-b do XYZ`のようにスラッシュスキルを連続で指定すると、最初のスキルだけでなく先頭から最大5つまでのスキルがすべて読み込まれるようになった。

[参考リンク](https://code.claude.com/docs/en/changelog#2.1.199)

## SSL証明書エラーの即時フィードバック

TLSインスペクションプロキシ、`NODE_EXTRA_CA_CERTS`未設定、期限切れ証明書などのSSL証明書エラーが、リトライを消費する前に即座に修正ヒント付きで失敗するようになった。

[参考リンク](https://code.claude.com/docs/en/changelog#2.1.199)

## ストリーミング応答の部分出力保持

APIがストリーミング中にオーバーロード/サーバーエラーを発行した場合、部分的な出力が破棄されずに保持され、未完了レスポンスの通知が表示されるようになった。

[参考リンク](https://code.claude.com/docs/en/changelog#2.1.199)

## サブエージェントの部分作業返却

[参考リンク](https://code.claude.com/docs/en/changelog#2.1.199)

## サブエージェントのAPIエラー報告改善
