## Workflowツールの追加

決定論的なマルチエージェントオーケストレーションのための`Workflow`ツールが追加された。デフォルトでは無効で、`CLAUDE_CODE_WORKFLOWS=1`を設定することで有効化できる。

[参考リンク](https://code.claude.com/docs/en/changelog)

## バックグラウンドセッションのピン留め機能

`claude agents`で`Ctrl+T`によりピン留めされたバックグラウンドセッションがアイドル時も維持されるようになった。Claude Codeの更新適用時にはその場で再起動され、メモリ圧迫時にはピン留めされていないセッションが先に解放される。

[参考リンク](https://code.claude.com/docs/en/changelog)

## /simplifyが/code-reviewにリネーム

`/simplify`が`/code-review`にリネームされた。選択した労力レベルで正確性のバグを報告する機能になり（例：`/code-review high`）、`--comment`を渡すとGitHub PRにインラインコメントとして投稿できる。以前のクリーンアップ・修正動作は削除された。

[参考リンク](https://code.claude.com/docs/en/changelog)

## REPLおよびWorkflowツールのサンドボックス強化

REPLおよびWorkflowツールのサンドボックスがプロトタイプ汚染やthenable based escapeに対して強化された。

[参考リンク](https://code.claude.com/docs/en/changelog)

## 自動アップデーターの改善

自動アップデーターが一時的なネットワーク障害をリトライするようになり、失敗時に具体的なエラーカテゴリとOSエラーコードを報告し、更新失敗時に現在のバージョンを表示するようになった。

[参考リンク](https://code.claude.com/docs/en/changelog)

## 大規模ファイル編集時のdiffレンダリング性能改善

大規模なファイル編集に対するdiffレンダリングのパフォーマンスが改善された。

[参考リンク](https://code.claude.com/docs/en/changelog)

## プロンプト履歴の重複排除

プロンプト履歴が連続する重複エントリを記録しなくなった。矢印キーでプロンプトを呼び出して再送信しても、もう一つのコピーが追加されることはない。

[参考リンク](https://code.claude.com/docs/en/changelog)

## バグ修正

エンタープライズログイン制限（`forceLoginOrgUUID`および`forceLoginMethod`マネージド設定）がサードパーティプロバイダーおよびAPIキーセッションに対して適用されていなかった問題が修正された。`!`コマンド出力中の`&`が`&amp;`として表示され、`gcloud auth login`などのコマンドのURL コピー＆ペーストが壊れる問題が修正された。ヘッドレス/SDKモードで不明なスラッシュコマンドが何も起こらない問題が修正され、エラーメッセージが表示されるようになった。`/help`が小さなターミナルでフルスクリーンモード外のときにタブヘッダーが壊れ1ページに1コマンドしか表示されない問題が修正された。シェルスナップショットが先頭にアンダースコア1つのユーザー関数を削除してしまい、それを参照するエイリアスが壊れる問題が修正された。プラグインエージェントが`tools:`フロントマターで複数の`Agent(...)`タイプを宣言した場合に最後のエントリ以外が失われる問題が修正された。フック`if`条件で`PowerShell(git push*)`がマッチしない問題が修正された。PowerShellツールがデフォルトフォーマッターに依存するコマンドの出力を失う問題が修正された。Windowsで「Yes, and don't ask again」によるPowerShellスクリプト呼び出しのルールが次回実行時にマッチしない問題が修正された。wingetまたはMicrosoft Store経由でインストールされた`pwsh`でPowerShellツールがexitコード1で失敗する問題が修正された。`/effort`のスライダーが現在のレベルではなく誤ったレベルで開く問題が修正された。MCPサーバーのページネーションでページ1以降のリソース・テンプレート・プロンプトが失われる問題が修正された。Windows TerminalでClaude ストリーミング中にアタッチされたバックグラウンドセッションのフルスクリーンがちらつく問題が修正された。WindowsでバックグラウンドジョブのworktreeをNTFSジャンクションがメインリポジトリを辿って削除する問題が修正された。`/background`がスキルまたはカスタムスラッシュコマンドのみの入力を拒否する問題が修正された。自動モードがユーザーまたはスキルが明示的に依存している`AskUserQuestion`を抑制する問題が修正された。`/theme`の「New custom theme」およびカラーエディタダイアログがEscに反応しない問題が修正された。Agent SDK経由でのストリーミングセッション終了時のキャッチされない例外が修正された。Windowsでスクロール安定待ち中のまれなハングが修正された。バックグラウンドセッションの結果にワイド文字（CJK）が含まれる場合にエージェントビューリストの行が古くなったり重複する問題が修正された。貼り付けたテキストが実際のコンテンツではなく`[Pasted text #N]`プレースホルダーとしてエージェントに配信される問題が修正された。プラグインのマニフェストがデフォルトディレクトリと重複するパスを列挙した場合に`claude plugin details`と`/plugin`のコンポーネント数が倍になる問題が修正された。バックグラウンド化されたセッションが「don't ask again」で既に許可したツール権限を再度プロンプトする問題が修正された。GNOME Terminalの右クリックおよび中クリックでテキストが挿入されない問題が修正された。`CLAUDE_CODE_SUBAGENT_MODEL`がエージェントチームで生成されたチームメイトプロセスに適用されない問題が修正された。スラッシュコマンドの後にタブまたは改行が続く場合に不明なコマンドとして扱われる問題が修正された。`/plugin`、`/status`、`/mobile`、`/sandbox`、`/permissions`メニューの間隔やレイアウトの不具合が修正された。ストリップされた画像がモデルに繰り返し存在しないメディアを再読み込みさせる問題が修正された。

[参考リンク](https://code.claude.com/docs/en/changelog)
