## Fable 5モデル名の1Mサフィックス正規化

Fable 5モデル名に`[1m]`サフィックスが付いている場合、自動的に除去されるようになった。Fable 5はデフォルトで1Mコンテキストを含むため、サフィックスは不要。

[参考リンク](https://code.claude.com/docs/en/changelog)

## Windowsサンドボックス起動時の警告修正

設定でサンドボックスが有効化されている場合に、Windows上で「sandbox dependencies missing」という不要な起動警告が表示される問題が修正された。

[参考リンク](https://code.claude.com/docs/en/changelog)
