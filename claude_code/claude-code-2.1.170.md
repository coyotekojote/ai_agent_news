## Claude Fable 5モデルのサポート

Mythos級モデルであるClaude Fable 5が導入された。Anthropicがこれまでに一般提供した中で最も高い能力を持つモデルであり、バージョン2.1.170にアップデートすることで利用可能になる。

[参考リンク](https://www.anthropic.com/news/claude-fable-5-mythos-5)

## VS Code統合ターミナルからのセッション保存の修正

VS Codeの統合ターミナルや、Claude Code環境変数を継承したシェルから起動した場合に、セッションのトランスクリプトが保存されず`--resume`に表示されない問題が修正された。

[参考リンク](https://code.claude.com/docs/en/changelog)
