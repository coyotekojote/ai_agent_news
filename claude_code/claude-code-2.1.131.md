## VS Code 拡張機能の Windows 起動修正

バンドルされた SDK の `createRequire` ポリフィルバグにより、Windows で VS Code 拡張機能がアクティベートに失敗する問題が修正された。

[参考リンク](https://github.com/anthropics/claude-code/releases/tag/v2.1.131)

## Mantle エンドポイント認証修正

Mantle エンドポイントの認証で `x-api-key` ヘッダーが欠落して失敗する問題が修正された。

[参考リンク](https://github.com/anthropics/claude-code/releases/tag/v2.1.131)
