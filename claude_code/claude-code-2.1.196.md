## ReportFindings SDKツールの追加

コードレビューの結果を構造化して報告するための`ReportFindings`ツールがSDKに追加された。レビューの努力レベル（low/medium/high/xhigh/max）、ファイルパス・行番号・サマリー・失敗シナリオを含む構造化された発見事項（最大32件）、検証結果（CONFIRMED/PLAUSIBLE）、修正後の結果追跡（fixed/skipped/no_change_needed）をサポートする。

[参考リンク](https://www.npmjs.com/package/@anthropic-ai/claude-code/v/2.1.196)

## DesignSyncのdescriptionフィールド追加

DesignSyncツールにギャラリーカードのサブタイトルとして表示される`description`フィールドが追加された。ページの内容や機能を一文で説明するために使用される。

[参考リンク](https://www.npmjs.com/package/@anthropic-ai/claude-code/v/2.1.196)
